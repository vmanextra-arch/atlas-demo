# Atlas — демонстрация проекта

[Открыть демонстрацию](https://vmanextra-arch.github.io/atlas-demo/)

Интерактивный глобус, поиск по странам и городам, 39 достопримечательностей с вращаемыми 3D-моделями и избранное, которое сохраняется в браузере.

Эта версия подготовлена для демонстрации школьного проекта. Изображение Земли, облака, каталог и модели загружаются из файлов этого сайта. Для просмотра требуются JavaScript и WebGL. Избранное хранится на устройстве посетителя.

Публикация в GitHub Pages выполняется из ветки `main`, каталога `/(root)`. В репозитории находятся готовые статические файлы. Для локального просмотра можно запустить любой HTTP-сервер в каталоге репозитория, например `python -m http.server 8080`, и открыть `http://localhost:8080`.
